# Calculator

A browser-based calculator project built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

The goal of this project is to combine JavaScript fundamentals with DOM manipulation and event handling by building an on-screen calculator.

The calculator will support the basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

The calculation logic will be implemented manually without using `eval()` or `new Function()`.

## Planned Features

- Number input
- Basic arithmetic operations
- Calculator display
- Clear button
- Chained calculations
- Consecutive operator handling
- Division-by-zero handling
- Long decimal result rounding
- Starting a new calculation after displaying a result

### Extra Credit

- Decimal number input
- Backspace button
- Keyboard support
