# Calculator

A browser-based calculator built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## About

The goal of this project was to combine JavaScript fundamentals with DOM manipulation and event handling by building a fully functional on-screen calculator.

The calculation logic is implemented manually without using `eval()` or `new Function()`.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Multi-digit number input
- Decimal number input
- Calculator display
- Clear button
- Backspace button
- Chained calculations
- Consecutive operator handling
- Division-by-zero handling
- Long decimal result rounding
- Starting a new calculation after displaying a result
- Keyboard support

## Keyboard Controls

- `0-9` — Number input
- `+` — Addition
- `-` — Subtraction
- `*` — Multiplication
- `/` — Division
- `.` — Decimal point
- `Enter` — Equals
- `Backspace` — Delete last input
- `Escape` — Clear calculator
